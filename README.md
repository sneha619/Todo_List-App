# Todo List App

A feature-rich Todo List application built with React.js that helps users manage personal tasks with ease. It includes secure user authentication using JWT and HTTP-only cookies, ensuring each user’s data remains private and persistent. With drag-and-drop functionality, dark/light mode toggle, and a clean, responsive UI, this app offers both usability and a great user experience.

Deployed link - https://todo-frontend-wgje.onrender.com/
---

## ✨ Features

- Add, edit, and delete tasks  
- Mark tasks as completed  
- Drag and drop to reorder tasks  
- Light/Dark mode toggle  
- Secure user login with JWT & HTTP-only cookies  
- Fully responsive design  
- Persistent data using LocalStorage  

---

## 🛠️ Technologies Used

- React.js – Frontend library  
- Tailwind CSS – Utility-first styling  
- CSS – Custom styling  
- LocalStorage – Temporary client-side data persistence  
- JWT (JSON Web Tokens) – Authentication  
- HTTP-only Cookies – Secure token storage

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed:

- [Node.js](https://nodejs.org/)  
- npm (comes with Node.js)

---

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sneha619/Todo_List-App.git
2. **cd Todo_List-App/Project/my-todo-app**
3. **Install dependencies:**
   -npm install
4. **Run the development server:**
   -npm start
   
📌 Usage

1. Add tasks: Enter a task name in the input field and click "Add".

2. Edit tasks: Modify task text inline before saving.

3. Complete tasks: Click the checkbox to mark as done.

4. Delete tasks: Click the delete icon to remove a task.

5. Reorder tasks: Drag and drop tasks to reorder them as needed.

6. Dark mode: Toggle between light and dark themes using the UI switch.

7. Tasks persist via LocalStorage, so they remain after page refresh.
