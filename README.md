# Todo List App

A simple Todo List application built with **React.js**. This project allows users to add, delete, and mark tasks as complete. It’s a great way to manage personal tasks with an easy-to-use interface.

## Features

- Add new todo items
- Delete todo items
- Mark todo items as completed
- Responsive design

## Technologies Used

- **React.js** - Frontend Framework
- **CSS** - Styling
- **LocalStorage** - For storing todos persistently

## Prerequisites

Before you begin, ensure you have the following installed on your local machine:

- **Node.js**: [Download Node.js](https://nodejs.org/)
- **npm** (Node Package Manager) comes with Node.js, so if you have Node.js, you already have npm installed.

## Installation

Follow these steps to get a local copy of the project up and running:

1. **Clone the repository** to your local machine:

   ```bash
   git clone https://github.com/sneha619/Todo_List-App.git
2. Navigate to the project directory: cd Todo_List-App/Project/my-todo-app
3. Install the dependencies: npm install
4. Run the app: npm start
This will start the development server, and you can view the app at http://localhost:3000 in your browser.

Usage
1. Once the app is running, you can:

2. Add tasks: Enter a task name in the input field and press the "Add" button.

3. Mark tasks as completed: Click the checkbox next to the task to mark it as complete.

3. Delete tasks: Click the "Delete" button next to the task to remove it from the list.
   
The tasks will persist in the browser's local storage, so even if you refresh the page, your tasks will still be there.
